Browser-local ZIP inspection

ZIPs and repository source never leave this browser. No repository code executes. Only individually reviewed declarations can be sent for synthetic tests. Privacy scanning is fallible: inspect every outgoing field, including evidence paths. Synthetic success is not live acceptance.

Limits: 8 MiB ZIP, 16 MiB expanded, 256 entries, 1 MiB per file, 100:1 expansion. Nested archives and private paths are excluded without extraction.

Live host

Live not connected. This public service has no live gate endpoint. No signing or qualification service is simulated.
